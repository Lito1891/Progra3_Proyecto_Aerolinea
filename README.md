Proyecto aerolinea
Este repositorio contiene el proyecto final del curso de Programación 3.
El objetivo es desarrollar una página web para una aerolinea ficticia utilizando HTML, CSS y Bootstrap.

¡Cómo empezar?

Clonar el repositorio

git clone https://github.com/Lito1891/Progra3_Proyecto_Aerolinea.git

Entrar en la carpeta del proyecto

cd Progra3_Proyecto_Aerolinea

-- luego de entrar a la carpeta ingresen el comando "git pull" para que les "jale" lo que haya en el repositorio
-- Para subir al repositorio sus avances hagan lo siguiente:
  1. "git add ."
  2. "git commit -m "mensaje de ejemplo"" por ejemplo = git commit -m "Se crean más carpetas de tal cosa" (siempre el mensaje entre comillas)
  3. "git push" (para subir lo que tengan de avance y que todos al ahcer pull lo descarguen y todos tengan todo de todos)

Cada colaborador debe crear su propia rama para trabajar: bash git checkout -b nombre-rama
📝 Buenas prácticas- Usar mensajes de commit claros y descriptivos.

No trabajar directamente en la rama main.
Revisar los Pull Requests de otros compañeros antes de aprobarlos.
Mantener la carpeta img organizada y con nombres de archivo simples (ejemplo: aerolinea.jpg, no aerolinea Ficticia final 1.JPG).
